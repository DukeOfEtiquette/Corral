# Decisions

Department-local Architectural Decision Records (ADRs) for the `Backend API` department.

## ADR body convention

The body convention (frontmatter schema, status values, section structure, append-only rule) is defined in the coordinator's decisions README at `ai-infrastructure/project-manager/decisions/README.md`. Follow that convention for all department-local ADRs.

## Department-local numbering

The numbering scheme for department-local ADRs (for example `ADR-001-...` restarting from 1, or a namespaced scheme) is left to the department's first ADR. No scheme is imposed by the scaffold recipe.

## Scope

ADRs here capture decisions that are specific to this department's work. Cross-cutting or project-wide decisions belong in the coordinator's `decisions/` directory at `ai-infrastructure/project-manager/decisions/`.
