## Decisions made

- **`extract_body` is a standalone helper, not an inline expression inside `collect_adrs`.** The frontmatter-stripping logic matches the boundary condition in `parse_frontmatter` (same `text.find("\n---", 3)` pattern) for consistency; a separate function keeps `collect_adrs` readable.
- **`AdrModal` is a sibling component to `WorkspaceDetailFull`, not inlined.** The modal has its own `useEffect` lifecycle for the Escape listener; a named component is cleaner than embedding it.
- **Modal `aria-label` is the ADR title string.** The kickoff specified `role="dialog" aria-modal`; `aria-label` was added for screen-reader accessibility following the same pattern as rogue's exemplar.
- **`npm install` run on host.** The kickoff names `package-lock.json` as part of the deliverable; the run policy (ADR-003) governs the ETL/build, not manifest installation. npm was available on the host (confirmed via `which npm`), so the lockfile was regenerated in place.
